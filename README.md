# StylE ME

**상의·하의·신발을 조합하고, 마음에 드는 코디를 기록하는 Android 앱**

원하는 의상을 선택해 다양한 조합을 비교하고, 저장한 코디에 이름과 메모를 남길 수 있습니다.

> 모바일 프로그래밍 수업의 중간 프로젝트입니다. 현재는 기본적인 코디 구성과 앱 실행 중 저장·편집 기능을 구현했으며, 기말 프로젝트에서 기능을 확장할 예정입니다.

## 프로젝트 소개

- **개발자:** 최석인
- **개발 형태:** 개인 프로젝트
- **개발 언어:** Kotlin
- **UI:** Jetpack Compose
- **개발 환경:** Android Studio

## 주요 기능

### 1. 의상 선택 및 코디 구성

- 상의·하의·신발을 각각 독립적으로 선택할 수 있습니다.
- 각 카테고리에 10개의 의상 이미지를 제공합니다.
- `Prev`와 `Next` 버튼으로 이전·다음 의상을 확인합니다.
- 첫 번째와 마지막 이미지 사이를 순환하며 탐색할 수 있습니다.

### 2. 코디 저장 및 목록 확인

- `Save This Outfit` 버튼으로 현재 선택한 조합을 저장합니다.
- 저장한 코디는 목록에 추가되며, 저장 개수가 즉시 반영됩니다.
- 선택 영역의 의상을 변경해도 기존에 저장한 조합은 유지됩니다.
- 동일한 조합을 여러 번 저장할 수 있습니다.

### 3. 코디 상세 확인 및 편집

- 저장한 코디 카드를 펼쳐 의상 이미지와 상세 정보를 확인합니다.
- 코디의 이름과 메모를 입력하거나 수정할 수 있습니다.
- 별도의 저장 버튼 없이 입력 내용이 즉시 반영됩니다.
- 수정한 이름은 카드 제목에도 반영되며, 카드를 접어도 입력 내용이 유지됩니다.

## 화면 구성

화면 상단에는 로고와 앱 제목을 고정하고, 아래에는 `LazyColumn`을 사용해 의상 선택 영역과 저장 목록을 스크롤할 수 있도록 구성했습니다.

```text
StylE ME
├── 로고 및 앱 제목
└── 스크롤 영역
    ├── 상의 선택
    ├── 하의 선택
    ├── 신발 선택
    ├── 코디 저장 버튼
    └── 저장한 코디 목록
        ├── 저장 개수
        └── 코디 카드
            ├── 코디 이름
            └── 펼침 영역
                ├── 저장한 의상 이미지
                ├── 이름 입력
                └── 메모 입력
```

## 구현 내용

### 상태 관리

`StyleMeScreen`에서 의상 선택 상태와 저장 목록을 관리합니다. 선택한 이미지와 저장 목록이 변경되면 화면에 반영되도록 Compose의 상태 관리를 사용했습니다.

- `remember`와 `mutableStateOf`로 카테고리별 선택 위치 관리
- `mutableStateListOf<SavedOutfit>`으로 저장 목록 관리
- 부모 컴포저블에서 선택 상태와 저장 데이터를 공유
- 카드의 펼침 여부는 해당 카드 내부에서 관리

### 컴포넌트 구성

| 구성 요소             | 역할                              |
| ----------------- | ------------------------------- |
| `StyleMeScreen`   | 전체 화면 구성과 의상 선택·저장 목록 상태 관리     |
| `ClothesSelector` | 카테고리별 의상 이미지 및 이전·다음 버튼 표시      |
| `SavedOutfitCard` | 저장한 코디 표시, 상세 영역 펼침·접힘 및 편집     |
| `SavedOutfit`     | 상의·하의·신발 이미지와 이름·메모를 담는 데이터 클래스 |

상의·하의·신발 선택 영역은 공통 컴포저블인 `ClothesSelector`를 재사용합니다. 이름과 메모의 변경 사항은 콜백으로 부모에 전달하고, `copy()`를 사용해 저장 목록의 데이터를 갱신합니다.

## 현재 제한 사항

- 저장한 코디는 메모리에서만 관리합니다.
- 앱을 종료하거나 화면이 재생성되면 저장한 코디와 입력 내용이 유지되지 않습니다.
- 의상은 앱에 포함된 이미지 리소스에서 선택합니다.

## 학습 내용

- Jetpack Compose를 활용한 선언형 UI 구성
- 상태 변경에 따른 화면 갱신
- 상태 호이스팅과 콜백을 통한 데이터 전달
- 공통 컴포저블을 활용한 UI 재사용
- `LazyColumn`을 활용한 스크롤 목록 구성
- 데이터 클래스와 `copy()`를 활용한 상태 갱신
